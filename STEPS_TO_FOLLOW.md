# Steps to follow for the complete project

1. Follow [environment setup](docs/SETUP.md) and run the initial checks.
2. Open the [40-session index](sessions/README.md).
3. For each numbered folder, read its README and instructor notes, implement its
   `STEPS_TO_FOLLOW.md`, run `reference.py`, and complete `evidence.md`.
4. Keep the same repository and retain passing checks from previous sessions.
5. At each module boundary, follow [cumulative integration steps](docs/INTEGRATION_STEPS.md).
6. Compare actual results with the original plan and the
   [implementation ledger](docs/IMPLEMENTATION_STATUS.md). A local experiment or
   preflight does not certify an unrun live integration.
7. Complete the reviewed evaluation, security and clean deployment gates before
   calling the final system release-ready.
