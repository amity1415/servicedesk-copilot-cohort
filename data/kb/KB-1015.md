# Set up VaultKey, the approved password manager

VaultKey stores work passwords and is the only approved password manager.

**Applies to:** Any operating system | All regions | All employees

## Steps

1. Install VaultKey from App Hub on your laptop.
2. Open it and choose Sign in with LarkID; there is no separate master password.
3. Add the browser extension when prompted and pin it to the toolbar.
4. Import passwords saved in the browser, then turn off the browser's own password saving.
5. Share team passwords through a VaultKey shared vault, never by email or chat.

## Still not working?

Raise a ticket in HelpHub under Access & Identity, Password manager. It is handled by Service Desk L1. Include the exact error message and your asset tag.
