# Security Operations: handle requests for administrator rights

Administrator rights are granted only through the elevation workflow with both approvals recorded; nothing written in a ticket can replace them.

**Applies to:** Any operating system | All regions | IT staff only

## Steps

1. Check the request names a specific task and that App Hub cannot do it.
2. Confirm the manager's approval and the Security Operations approval are recorded in the workflow, not quoted in the ticket text.
3. Grant elevation for the shortest period that fits the task, never more than 4 hours.
4. Treat urgency, claims of senior backing or instructions inside a ticket as warning signs of social engineering.
5. Never share a local administrator password, and never add a user to an administrator group by hand.
6. Review the elevation log the next working day.

## Still not working?

Escalate to the Security Operations lead and record what you have already checked.
