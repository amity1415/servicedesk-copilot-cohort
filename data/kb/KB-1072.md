# Free up disk space on macOS

Keep at least 15 percent of the disk free; OneDrive can keep files online only so they stop using local space.

**Applies to:** macOS | All regions | All employees

## Steps

1. Open System Settings, General, Storage, to see what is using space.
2. Choose Empty Trash automatically and review Large Files under Documents.
3. In Finder right-click the OneDrive folder and choose Free Up Space.
4. Empty the Downloads folder.
5. Delete applications you no longer use from the Applications folder.
