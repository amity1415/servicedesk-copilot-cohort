# Printing fails with error 0x00000709 on Windows

Error 0x00000709 means Windows cannot set or reach the default printer; removing and re-adding the queue clears it.

**Applies to:** Windows | All regions | All employees

## Symptoms

- 'Operation could not be completed (error 0x00000709). Double check the printer name and make sure that the printer is connected to the network.'

## Likely causes

- Windows is managing the default printer and chose one that no longer exists.
- The print queue was renamed after an office move.

## Resolution

1. Open Settings, Bluetooth and devices, Printers and scanners.
2. Turn off Let Windows manage my default printer.
3. Remove any FollowMe queue listed.
4. Open App Hub and run Add office printers.
5. Back in Printers and scanners, select the FollowMe queue and choose Set as default.
