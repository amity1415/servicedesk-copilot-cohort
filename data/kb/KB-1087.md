# Using USB storage devices

USB sticks and drives are read-only on company laptops; writing to them needs an approved exception and a company-issued encrypted stick.

**Applies to:** Any operating system | All regions | All employees

## Steps

1. You can read files from any USB storage device; they are scanned when opened.
2. Copying files to USB storage is blocked by default.
3. If you must write to USB for work, raise a HelpHub request for a removable media exception.
4. Your manager and Security Operations approve; exceptions last at most 90 days.
5. Use only the encrypted stick IT issues with the exception. Restricted data must never be copied to removable media.

## Still not working?

Raise a ticket in HelpHub under Security, Removable media. It is handled by Security Operations. Include the exact error message and your asset tag.
