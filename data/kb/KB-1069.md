# Windows laptop restarts with a blue screen

A single blue screen is usually harmless; a repeating one needs IT, and the stop code on the screen tells them where to look.

**Applies to:** Windows | All regions | All employees

## Symptoms

- A blue screen with a sad face and a stop code such as CRITICAL_PROCESS_DIED or DRIVER_IRQL_NOT_LESS_OR_EQUAL.

## Likely causes

- A faulty or outdated driver, often for a dock or graphics.
- Failing memory or disk.
- An interrupted update.

## Resolution

1. Write down or photograph the stop code before the laptop restarts.
2. After the restart, open Settings, Windows Update and install everything offered.
3. Open App Hub and run Driver updates.
4. Disconnect the dock for a day to see whether the crashes stop.
5. If it happens again within a week, raise a ticket with the stop code, the time and what you were doing.

## Still not working?

Raise a ticket in HelpHub under Hardware & Devices, Crashes. It is handled by Workplace Engineering. Include the exact error message and your asset tag.
