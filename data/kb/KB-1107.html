Network Operations: diagnose VPN error 809 that follows the user

Error 809 on every network is not a home router fault; check the NAT traversal setting, the local firewall and the gateway.

Applies to: Any operating system | All regions | IT staff only

Symptoms

  • The user gets error 809 on home broadband, on a phone hotspot and on guest Wi-Fi.

Likely causes

  • The NAT traversal registry value is missing after a rebuild.
  • A third-party firewall product is installed.
  • The regional gateway is rejecting new sessions.

Resolution

  1. Check the gateway dashboard for the user's region; more than five 809 tickets in an hour is a gateway incident.
  2. On the laptop confirm the registry value AssumeUDPEncapsulationContextOnSendRule under HKLM\SYSTEM\CurrentControlSet\Services\PolicyAgent is 2.
  3. If it is missing, run the Network baseline policy from the management console and restart.
  4. Check for third-party firewall or VPN software and remove it.
  5. Collect the SecureTunnel log bundle and attach it before closing or escalating to the vendor.

Still not working?

Escalate to the Network Operations lead and record what you have already checked.
