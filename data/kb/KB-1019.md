# VPN is connected but internal sites do not load on Windows

When the VPN shows connected but intranet pages time out, the laptop is usually still using the home network's DNS servers.

**Applies to:** Windows | All regions | All employees

## Symptoms

- SecureTunnel shows connected.
- Public websites load but intranet.larkhaven.example does not.

## Likely causes

- A stale DNS cache.
- A manually configured DNS server on the network adapter.
- A browser secure-DNS setting that bypasses the VPN.

## Resolution

1. Disconnect and reconnect SecureTunnel.
2. Open Command Prompt and run: ipconfig /flushdns
3. Open Settings, Network and internet, your adapter, and set DNS server assignment to Automatic.
4. In the browser settings turn off Use secure DNS.
5. Test with https://intranet.larkhaven.example.
