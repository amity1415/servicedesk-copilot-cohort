VPN is connected but internal sites do not load on macOS

When the VPN shows connected but intranet pages time out, the laptop is usually still using the home network's DNS servers.

Applies to: macOS | All regions | All employees

Symptoms

  • SecureTunnel shows connected.
  • Public websites load but intranet.larkhaven.example does not.

Likely causes

  • A stale DNS cache.
  • A manually configured DNS server on the network adapter.
  • A browser secure-DNS setting that bypasses the VPN.

Resolution

  1. Disconnect and reconnect SecureTunnel.
  2. Open Terminal and run: sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
  3. Open System Settings, Network, your connection, Details, DNS, and remove any servers you added by hand.
  4. In the browser settings turn off Use secure DNS.
  5. Test with https://intranet.larkhaven.example.

Still not working?

Raise a ticket in HelpHub under Network & VPN, VPN. It is handled by Network Operations. Include the exact error message and your asset tag.
