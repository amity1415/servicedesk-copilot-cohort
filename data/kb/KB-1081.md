# Fix a website that does not load or display properly

Clearing saved site data fixes most web application problems; only extensions from the approved list can be installed.

**Applies to:** Any operating system | All regions | All employees

## Symptoms

- A web application shows a blank page, an endless spinner or an old version.
- A site works in a private window but not in a normal one.

## Likely causes

- Out-of-date cached files or cookies.
- A browser extension interfering with the page.

## Resolution

1. Open the site in a private or InPrivate window. If it works there, continue below.
2. Press Ctrl + Shift + Delete (Cmd + Shift + Delete on a Mac), choose Cached images and files and Cookies for the last 7 days, and clear.
3. Turn off extensions one at a time to find the one that breaks the page.
4. Try the other supported browser; Chrome and Edge are both supported.
5. Extensions come only from the approved list in the browser's managed store. Request a new one through HelpHub.

## Still not working?

Raise a ticket in HelpHub under Software, Browser. It is handled by Service Desk L1. Include the exact error message and your asset tag.
