# Connect to LarkNet, the office Wi-Fi on Windows

Company laptops join LarkNet automatically with a certificate; you never type a Wi-Fi password.

**Applies to:** Windows | All regions | All employees

## Steps

1. Select the network icon in the taskbar and choose LarkNet.
2. If Windows asks for a user name and password, cancel; the certificate is missing.
3. Connect a network cable or use the LarkGuest network with VPN, then open App Hub and run Repair network certificate.
4. Restart and select LarkNet again; it connects without prompting.

## Good to know

- Phones and personal devices cannot join LarkNet. Use the guest network instead.
