# Messaging: rebuild an Outlook profile safely

A profile rebuild fixes most connection and search faults, but local-only data must be checked first.

**Applies to:** Any operating system | All regions | IT staff only

## Steps

1. Confirm the mailbox is healthy in webmail.
2. Check for local PST files under Account Settings, Data Files; a new profile does not reconnect them automatically.
3. Export the user's signatures and rules if they have many.
4. Create the new profile from Control Panel, Mail; do not delete the old one until the new one has synchronised.
5. Set the cached mode slider to 12 months for mailboxes above 20 GB.
6. Remove the old profile after two working days without problems.

## Still not working?

Escalate to the Messaging & Collaboration lead and record what you have already checked.
