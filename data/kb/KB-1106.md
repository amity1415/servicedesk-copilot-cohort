# Known issue KI-2026-014: SecureTunnel 5.2 disconnects on macOS 26

SecureTunnel 5.2 drops the tunnel every 8 to 12 minutes on macOS 26 when private Wi-Fi addressing rotates; version 5.3 fixes it.

**Applies to:** Any operating system | All regions | IT staff only

## Symptoms

- Mac users on macOS 26 report drops at regular intervals.
- The client log shows 'peer address changed, tearing down'.

## Likely causes

- Version 5.2 treats a rotated private Wi-Fi address as a new device.

## Resolution

1. Confirm the client version in SecureTunnel, About.
2. Deploy version 5.3 from App Hub; it is in the general ring since 20 October 2026.
3. If the Mac cannot update at once, set Private Wi-Fi Address to Fixed for the home network as a workaround.
4. Link the ticket to problem record KI-2026-014 and do not escalate to Network Operations.

## Still not working?

Escalate to the Network Operations lead and record what you have already checked.
