# Mac restarts with 'Your computer restarted because of a problem'

This message is a kernel panic; one is harmless, repeated ones point to an accessory, an old system extension or failing hardware.

**Applies to:** macOS | All regions | All employees

## Symptoms

- The Mac restarts unexpectedly and shows 'Your computer restarted because of a problem' after login.

## Likely causes

- A dock, adapter or other accessory.
- Outdated software that installs a system extension.
- Failing hardware.

## Resolution

1. Choose Report when the message appears so the details are saved.
2. Disconnect every accessory and use the Mac on its own for a day.
3. Open System Settings, General, Software Update and install what is offered.
4. Update SecureTunnel and EndpointShield from App Hub.
5. If it happens again within a week, raise a ticket and say whether accessories were connected.

## Still not working?

Raise a ticket in HelpHub under Hardware & Devices, Crashes. It is handled by Workplace Engineering. Include the exact error message and your asset tag.
