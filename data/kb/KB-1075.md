# Install software from App Hub on Windows

App Hub installs approved software without administrator rights; anything not listed there must be requested.

**Applies to:** Windows | All regions | All employees

## Steps

1. Open App Hub from the Start menu.
2. Search for the application and choose Install; free applications install at once.
3. Applications marked Licence required open a request form instead; see Request licensed software.
4. Keep the laptop awake and online until the status shows Installed.
5. If an installation stays at Pending for more than 30 minutes, restart and choose Retry.

## Still not working?

Raise a ticket in HelpHub under Software, Installation. It is handled by Software Packaging. Include the exact error message and your asset tag.
