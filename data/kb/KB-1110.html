Software Packaging: reclaim unused licences

A licence unused for 60 days is reclaimed after a 7-day warning; reclaiming early needs the holder's agreement.

Applies to: Any operating system | All regions | IT staff only

Steps

  1. Run the Unused licences report for the application; it lists the last-used date for each holder.
  2. The warning email is sent automatically at day 53.
  3. At day 60 the licence returns to the pool and the application is removed at the next check-in.
  4. When a request is waiting and no licence is free, you may ask the longest-idle holder to release theirs early; record their reply.
  5. Never reclaim from a user on long-term leave without asking their manager.
  6. FinSight uses named licences: update the holder in the FinSight admin page as well as in the pool.

Still not working?

Escalate to the Software Packaging lead and record what you have already checked.
