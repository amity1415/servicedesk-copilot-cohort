# OneDrive is not syncing on Windows

OneDrive stops syncing when it cannot sign in, when a file name is not allowed, or when the disk is full.

**Applies to:** Windows | All regions | All employees

## Symptoms

- The cloud icon shows a red cross or arrows that never finish.
- On Windows, 'There was a problem connecting to OneDrive' with error 0x8004de40.

## Likely causes

- An expired sign-in.
- File names with characters such as * : < > ? or a path longer than 400 characters.
- Less than 1 GB of free disk space.

## Resolution

1. Select the OneDrive cloud icon and read the message it shows.
2. For error 0x8004de40, check the internet connection, then sign out of OneDrive from Settings, Account, and sign in again.
3. Rename files the sync client lists as not allowed.
4. Free up disk space until at least 1 GB is available.
5. Press Windows key + R and run: %localappdata%\Microsoft\OneDrive\onedrive.exe /reset
6. Start OneDrive again from the Start menu and allow up to an hour for a full re-check.
