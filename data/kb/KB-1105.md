# Identity and Access: reset MFA and issue a temporary access pass

An MFA reset is a high-risk action: it needs verified identity and a second Identity and Access analyst to approve.

**Applies to:** Any operating system | All regions | IT staff only

## Steps

1. Confirm identity by video call with the line manager or by badge at a Tech Bar; a push approval is not possible in this case.
2. Record the reason: lost, replaced, wiped or stolen phone.
3. Ask a second analyst to approve the reset in the admin console.
4. Remove the old authenticator registration.
5. Issue a temporary access pass valid for 60 minutes, single use.
6. Stay on the call until the user has registered the new device, then confirm the pass shows as used.

## Still not working?

Escalate to the Identity & Access lead and record what you have already checked.
