# EndpointShield quarantined a file (alert ES-QUAR-21)

ES-QUAR-21 means EndpointShield blocked a file it considers malicious and moved it to quarantine; no action is needed unless the file was legitimate.

**Applies to:** Any operating system | All regions | All employees

## Symptoms

- A notification says 'Threat quarantined. ES-QUAR-21' with a file name.

## Likely causes

- A malicious attachment or download.
- Occasionally, a legitimate tool that behaves like malware, such as a script or macro.

## Resolution

1. Do not try to restore the file yourself.
2. Note the file name and where it came from: an email, a website or a USB stick.
3. If it came from an email, report that email with the Report phishing button.
4. If you believe the file is legitimate work material, raise a ticket for Security Operations with the file name and the alert time.
5. If alerts repeat or the laptop behaves strangely, follow the article What to do if you suspect malware.

## Still not working?

Raise a ticket in HelpHub under Security, Endpoint protection. It is handled by Security Operations. Include the exact error message and your asset tag.
