Service desk: unlock an account in the LarkID admin console

Unlock on request only after finding where the failed sign-ins come from; otherwise the account locks again within minutes.

Applies to: Any operating system | All regions | IT staff only

Steps

  1. Verify the caller's identity.
  2. In the admin console open Users, the user, then Sign-in log, and filter on Failed.
  3. Note the source of the failures: device name, application and IP address.
  4. If the source is the user's own device, have them remove the old password there first.
  5. Choose Unlock account.
  6. If the failures come from an unknown address or several countries, do not unlock; assign to Security Operations as priority 2.

Still not working?

Escalate to the Identity & Access lead and record what you have already checked.
