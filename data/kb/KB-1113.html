Software Packaging: handle a request for new software

New software reaches App Hub after a security review, a licence check and a pilot; the target is 10 business days.

Applies to: Any operating system | All regions | IT staff only

Steps

  1. Check the catalogue for an approved application that already does the job; offer it first.
  2. Send the vendor, version and data handled to Security Operations for review; allow 5 business days.
  3. Ask Legal to check the licence terms for anything other than standard commercial or permissive open source.
  4. Package the application and release it to the pilot ring for 3 business days.
  5. Add it to the software catalogue with its charge and approval rule, then release to all.

Still not working?

Escalate to the Software Packaging lead and record what you have already checked.
