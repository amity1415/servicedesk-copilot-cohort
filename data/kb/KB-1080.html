macOS update does not install

macOS updates need the charger connected and about 25 GB free; major new versions appear only after IT has approved them.

Applies to: macOS | All regions | All employees

Symptoms

  • The update downloads and then nothing happens.
  • Software Update shows 'An error occurred while installing'.

Likely causes

  • Too little free disk space.
  • The Mac is on battery power.
  • The version is a major release that IT has not approved yet.

Resolution

  1. Connect the charger and free disk space until 25 GB is available.
  2. Restart the Mac, open System Settings, General, Software Update and choose Update Now.
  3. Leave the lid open until the Mac has restarted on its own.
  4. A major new macOS version is offered about 60 days after Apple releases it; before that it is hidden on purpose.
  5. If a security update fails twice, raise a ticket.

Still not working?

Raise a ticket in HelpHub under Software, Updates. It is handled by Software Packaging. Include the exact error message and your asset tag.
