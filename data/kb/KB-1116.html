Onboarding Team: fulfil a new joiner request

Fulfilment starts when HR has completed the PeopleHub record and finishes 2 business days before the start date.

Applies to: Any operating system | All regions | IT staff only

Steps

  1. Check the PeopleHub record is complete: legal name, start date, manager, cost centre and office.
  2. Create the LarkID account from the record; never type the details by hand.
  3. Apply the role profile; it adds the standard applications and groups.
  4. Assign and image the laptop, and record the asset tag against the employee.
  5. Assign licences from the pool; if none is free, tell the manager which application will be late.
  6. Create the temporary access pass 2 business days before the start date and send it to the manager, not to the joiner.

Still not working?

Escalate to the Onboarding Team lead and record what you have already checked.

Related policy: POL-009 Joiner, Mover and Leaver Policy.
