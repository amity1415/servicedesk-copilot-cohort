# Outlook cannot connect to the server (error 0x800CCC0E)

Error 0x800CCC0E means Outlook on Windows could not reach the mail server; the mail profile or the network path is at fault.

**Applies to:** Windows | All regions | All employees

## Symptoms

- Send and receive fails with 0x800CCC0E.
- The status bar shows Disconnected or Trying to connect.

## Likely causes

- Work Offline is switched on.
- A damaged Outlook profile.
- A proxy or security add-in is blocking the connection.

## Resolution

1. Open https://outlook.larkhaven.example in a browser. If webmail works, the mailbox is healthy.
2. In Outlook open the Send / Receive tab and make sure Work Offline is not highlighted.
3. Close Outlook, hold Ctrl while starting it, and choose Yes to start in safe mode. If it connects, disable add-ins one at a time.
4. Open Control Panel, Mail, Show Profiles, add a new profile and set it as default.
5. Start Outlook and let the mailbox synchronise; a large mailbox can take an hour.
