# Get access to FinSight, the finance reporting tool

FinSight is a restricted application: access needs your manager and the Finance data owner to approve, and a free named licence.

**Applies to:** Any operating system | All regions | All employees

## Steps

1. In HelpHub choose Request access and search for FinSight.
2. Pick a role: Viewer for reports, Analyst to build reports, Admin for the Finance systems team only.
3. State which cost centres or legal entities you need to see and why.
4. After your manager approves, the request goes to the Finance data owner, who answers within 2 business days.
5. If no licence is free, the request waits until one is reclaimed; licences unused for 60 days are reclaimed automatically.
6. On first sign-in open FinSight from the LarkID portal and accept the confidentiality notice.

## Good to know

- FinSight holds Restricted data. Reports must not be exported to personal devices or personal cloud storage.

## Still not working?

Raise a ticket in HelpHub under Access & Identity, Application access. It is handled by Identity & Access. Include the exact error message and your asset tag.
